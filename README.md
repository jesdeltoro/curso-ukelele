# 🌺 Curso Completo de Ukelele: De Cero a Músico

¡Bienvenido/a a tu curso de ukelele! Este proyecto contiene todo lo necesario para aprender a tocar el ukelele desde el primer día, con explicaciones claras, diagramas, vídeos, cancionero y herramientas interactivas.

🌐 **App Web en vivo (GitHub Pages)**: [https://jesdeltoro.github.io/curso-ukelele/](https://jesdeltoro.github.io/curso-ukelele/)

---

## 📂 Contenido del Curso

1. **[Curso_Completo_Ukelele.md](Curso_Completo_Ukelele.md)**:
   - **Manual maestro en formato Markdown**, ideal para leer, estudiar o imprimir.
   - Contiene 8 módulos detallados: anatomía, afinación gCEA, primeros acordes, rasgueo Calypso, técnica de Chuck, mini-cejillas, arpegios, cancionero completo (Somewhere Over the Rainbow, Riptide, Stand by Me, Limón y Sal...), plan de práctica de 30 días y enlaces directos a vídeos de YouTube.

2. **[index.html](index.html)**:
   - **Aplicación web interactiva**: Ábrela en tu navegador o disfrútala directamente en la web.
   - **Metrónomo digital integrado** con sonido sintetizado mediante Web Audio API (ajusta los BPM y practica a tu ritmo).
   - **Diagramas visuales de acordes interactivos**: pulsa en cualquier acorde para escuchar cómo debe sonar en tu ukelele afinado.
   - **Videoteca integrada**: botones de acceso directo a tutoriales en YouTube (Guitarraviva, Fatima & Ukepop, Marta Burgos, etc.).
   - **Seguidor del plan de 30 días**: casillas interactivas para marcar tus progresos diarios.

---

## 🚀 Cómo Empezar Hoy Mismo (Día 1)

1. **Abre la [App Web en GitHub Pages](https://jesdeltoro.github.io/curso-ukelele/)** o el archivo [index.html](index.html) localmente.
2. Abre el **[Afinador gratuito de ukelele](afinador.html)** en tu móvil. Puedes instalarlo desde el navegador y afina en estándar **gCEA**:
   - Cuerda 4 (superior): **Sol (G)**
   - Cuerda 3: **Do (C)**
   - Cuerda 2: **Mi (E)**
   - Cuerda 1 (inferior): **La (A)**
3. Ve al **Módulo 1** y aprende la posición del acorde **Do (C)** y **La menor (Am)**.
4. Enciende el metrónomo a **60 BPM** y practica tus primeros rasgueos hacia abajo.

¡A disfrutar de la música! 🎶
